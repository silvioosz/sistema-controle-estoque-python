# 📦 Sistema de Controle de Estoque em Python

Projeto desenvolvido como parte do **Projeto Integrado Multidisciplinar (PIM I)** do curso de **Análise e Desenvolvimento de Sistemas** da **Universidade Paulista (UNIP)**.

O sistema simula funcionalidades essenciais de controle de estoque e registro de vendas voltadas para o setor de *Food Service* (restaurantes, bares e lanchonetes), inspirando-se na lógica de operação de sistemas ERP corporativos.

---

## 🚀 Funcionalidades

- 📝 **Cadastro de Produtos:** Registro de itens com nome, preço unitário e quantidade inicial.
- 📋 **Listagem de Estoque:** Exibição clara e organizada de todos os produtos cadastrados e seus respectivos saldos.
- 🛒 **Registro de Vendas:** Baixa automática no estoque com atualização em tempo real do saldo restante.
- ⚠️ **Validação de Saldo:** Bloqueio de vendas quando a quantidade solicitada é maior que o estoque disponível.

---

## 🛠️ Tecnologias e Conceitos

- **Linguagem:** Python 3
- **Estruturas de Dados:** Listas (`list`) e Dicionários (`dict`)
- **Conceitos Aplicados:**
  - Modularização com funções (`def`)
  - Estruturas de decisão (`if`, `elif`, `else`)
  - Laços de repetição (`while`, `for`)
  - Tratamento de entradas e formatação de texto/números
